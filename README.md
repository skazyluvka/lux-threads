LUXE THREADS — Магазин дизайнерской одежды
Описание

Десктопное приложение для интернет-магазина дизайнерской одежды, разработанное на Java с использованием JavaFX. Приложение предоставляет пользователям возможность просматривать каталог товаров, добавлять их в корзину, оформлять заказы и оставлять отзывы. Продавцы могут управлять своими товарами, публикациями и промокодами. Администраторы имеют доступ к панели управления пользователями, заказами и категориями.
Технологии

Язык: Java 17

UI: JavaFX, FXML, CSS

База данных: PostgreSQL (через Supabase)

API: Supabase REST API, Supabase Auth, Supabase Storage

Сетевые запросы: OkHttp

Парсинг JSON: Gson

Сборка: Maven

Контроль версий: Git, GitHub

Структура проекта

src/main/java/org/clothingstore/
├── config/          # Конфигурация (SupabaseConfig)
├── controller/      # FXML-контроллеры экранов
├── model/           # Классы моделей данных
├── service/         # Сервисный слой (работа с API)
└── util/            # Утилиты (навигация, сессии, загрузка изображений)

src/main/resources/
├── org/clothingstore/fxml/   # FXML-разметка
└── org/clothingstore/css/    # CSS-стили

Функционал
Для покупателей:

Регистрация и авторизация

Просмотр каталога товаров с фильтрацией по категориям

Детальная карточка товара с выбором размера и количества

Добавление товаров в корзину

Оформление заказа с применением промокода

Оставление отзывов и оценок товаров

Для продавцов:

Управление товарами (добавление, редактирование, удаление)

Управление складскими остатками по размерам

Создание публикаций и взаимодействие с комментариями

Создание промокодов со скидками

Для администраторов:

Управление пользователями и их ролями

Управление категориями товаров

Просмотр и изменение статусов заказов

Управление промокодами
